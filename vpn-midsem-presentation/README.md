# VPN detection midsem presentation

An editable, 20-slide website presentation structure for the VPN detection research project. Slides currently contain only their titles, presenter assignments, and blank image spaces.

## Run

From this folder, run `npm install` and then `npm run dev`. Open the local URL shown by Next.js. Use the arrow keys to move through slides, `G` for the grid, and `P` for presenter notes.

## Edit slide text

All presenter names, slide titles, guidance text, and image-slot counts are stored in `data/presentation-store.ts`.
